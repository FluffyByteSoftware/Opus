# Opus -- Project Layout

The skeleton of the whole project: every folder, every file, one line each on what it's for.

```
Opus/
├── CLAUDE.md                          # working rules for the sessions
├── README.md                          # what Opus is and how to build it
├── .gitignore                         # build output, Content/, caches
├── .gitattributes                     # which file types go through Git LFS
├── Conductor/                         # the server
│   └── dev/                           # a Cargo workspace
│       ├── Cargo.toml                 # the workspace: its two members
│       ├── Cargo.lock                 # generated by Cargo
│       ├── conductor-tools/           # lib
│       │   ├── Cargo.toml             # one dependency: postgres
│       │   └── src/
│       │       ├── lib.rs             # lists the tools
│       │       ├── archivist.rs       # the database: the job functions, Pending, start and stop
│       │       ├── archivist/
│       │       │   ├── settings.rs    # reads postgres.cfg, adds settings it's missing
│       │       │   ├── worker.rs      # the one worker thread, its mailbox and connection
│       │       │   ├── schemas.rs     # runs the schemas, then the migrations, on every connect
│       │       │   └── status.rs      # running totals and slow jobs
│       │       ├── clock.rs           # UTC date and time, calendar math by hand
│       │       ├── constellations.rs  # the config: finds Content/, reads and checks conductor_globals.cfg
│       │       └── scribe.rs          # the log: one file per UTC day
│       └── conductor-launcher/        # bin -- the program
│           ├── Cargo.toml
│           └── src/
│               ├── main.rs            # starts the tools in order, runs the menu, shuts down
│               └── launcher.rs        # the admin's menu: L to view the log, Q to shut down
├── Ensemble/                          # the client -- not started
├── Content/                           # committed, except Assets/ and logs/; made on first run if missing
│   ├── Assets/                        # purchased art -- never committed
│   ├── cfg/conductor_globals.cfg      # Conductor's settings
│   ├── cfg/postgres.cfg               # where Postgres is, the login, the time limit, the slow-job limit
│   ├── logs/YYYY_MM_DD.scribe.log     # one log file per UTC day -- never committed
│   └── psql/
│       ├── defaults/schemas/accounts.sql  # the accounts table as first made
│       └── migrations/README.md       # the rules; numbered .sql files go here
└── Documentation/
    └── LLM/
        ├── STATUS.md                  # the bridge between sessions
        ├── TODO.md                    # deferred work and ideas
        ├── PROJECT_OPUS.md            # this file
        ├── PROTOCOL.md                # the server/client contract -- empty until networking
        ├── WRITINGSTYLE.md            # Jacob's voice for anything in the repo
        └── design/
            ├── conductor-tools.md     # the tools crate
            └── conductor-launcher.md  # the launcher crate
```

## The named pieces

Where each one lives is in the tree above.

| Name               | What it is                                    | State                        |
|--------------------|-----------------------------------------------|------------------------------|
| Conductor          | The server.  It owns the game state.          | Tools and launcher only      |
| Ensemble           | The client players run.                       | Not started, engine unpicked |
| conductor-tools    | Lib crate: the tools the server leans on.     | Built and tested             |
| conductor-launcher | Bin crate: the program and the admin's menu.  | Built and tested             |
| Scribe             | The log.                                      | Built and tested             |
| Constellations     | The config file and the settings it holds.    | Built and tested             |
| Archivist          | The database: PostgreSQL on its own thread.   | Built and tested             |
| The clock          | UTC date and time.                            | Built and tested             |
